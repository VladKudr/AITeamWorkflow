# transfer-limits-demo

Учебный проект для демонстрации полного цикла SDD-workflow (playbook, схема
sdd-roles): внутрибанковские переводы между счетами. Начальное состояние —
сервис переводов с базовыми проверками; через цикл OpenSpec добавляется
суточный лимит на переводы со счёта.

Маршрут по демо: `WALKTHROUGH.md`.
Запуск тестов: `python -m pytest -q`.
