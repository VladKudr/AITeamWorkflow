# Proposal: Суточный лимит переводов со счёта

## Интент
Ограничить суммарный объём переводов со счёта за календарные сутки (UTC),
чтобы закрыть требование комплаенса и снизить риск фрод-вывода серией
переводов. Интент-бриф: docs/intent-brief-add-daily-transfer-limit.md.

## Scope
В этом изменении:
- Проверка суточного лимита на сумму исходящих переводов счёта
- Конфигурируемое значение лимита, единое для всех счетов
- Новая ошибка DAILY_LIMIT_EXCEEDED

Вне scope (осознанно):
- Индивидуальные лимиты по счетам/клиентам
- Уведомления о срабатывании лимита (кандидат на следующий change)
- Лимиты на входящие переводы

## Затронутые команды и системы
Только сервис переводов (TransferService). Публичный интерфейс расширяется
обратно совместимо (лимит — параметр с умолчанием).

## Rollback-план
Установить значение лимита «без ограничения» (None) конфигурацией — поведение
возвращается к текущему без отката кода.
