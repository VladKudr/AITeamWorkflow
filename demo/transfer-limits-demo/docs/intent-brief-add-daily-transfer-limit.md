# Интент-бриф: суточный лимит переводов

## Проблема / возможность
Со счетов возможен неограниченный вывод средств серией переводов. Комплаенс
требует ограничить объём переводов со счёта в сутки; клиенты жалуются на
отсутствие защитного порога при компрометации доступа.

## Для кого
Все владельцы счетов сервиса; операционный контроль банка.

## Ценность и критерии успеха
- Снижение риска фрод-вывода: серия переводов сверх порога блокируется
- Критерий: перевод сверх суточного лимита отклоняется с внятной ошибкой;
  переводы в пределах лимита работают без изменений

## Scope
В этом изменении:
- Суточный лимит на СУММУ переводов со счёта (календарные сутки, UTC)
- Конфигурируемое значение лимита, единое для всех счетов

НЕ в этом изменении (осознанно):
- Индивидуальные лимиты по счетам/клиентам
- Уведомления клиента о срабатывании лимита (отдельное изменение)
- Лимиты на входящие переводы

## Что обидно сломать
- «Обычный перевод в пределах лимита проходит как раньше»
- «Перевод ровно в размер остатка лимита проходит» (граница — не отказ)
- «На следующие сутки лимит начинается заново»

## Ограничения
Обратная совместимость публичного интерфейса TransferService.
